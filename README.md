# 每日早盘简报

为 Rui 定制的持仓行情简报页面。纯静态，无后端。

## 结构
- `index.html` — 简报主页面，内含实时引擎（行情 / 要闻 / 走势归因）
- `archive/` — 历次早报归档
- `server.js` — 本地静态服务（Node，无依赖）

## 本地预览
```
node server.js 8899
```
本机 http://localhost:8899/ ，同一 WiFi 下手机 http://<本机IP>:8899/

## 实时数据源（均为浏览器端直连，无需服务器）
- 行情：腾讯 qt.gtimg.cn
- 上海金 / 美元指数 / 中证931743：东方财富 push2
- 基金净值：天天基金 pingzhongdata
- 要闻：新浪财经 7×24 快讯
